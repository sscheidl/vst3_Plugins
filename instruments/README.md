# Instruments

Plug-ins that turn MIDI into sound. They have no audio input and register in
the VST3 category `Instrument`.

| Project | Origin | Status |
| --- | --- | --- |
| [toy-piano-classic](toy-piano-classic/) | Port of `instruments/toy-piano` from Daisy-Seed | 0.3.2: builds, validated, tested and code-reviewed; 0.1.0 loads in Studio One, not yet listened to |
| [torus-classic](torus-classic/) | Kekulé: port of `instruments/physical-modeling` (Rings/Torus) from Daisy-Seed, without its reverb | 0.3.0: builds, validated and tested automatically; adds 4, 8 or 16 voices and rest for Plug-in Nap, neither reviewed nor tried in a DAW yet; 0.1.0 loads and plays in Studio One; Codex released 0.2.1 for the DAW test |
